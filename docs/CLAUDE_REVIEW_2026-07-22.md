## 2. プランの評価

### 良い点

- 「300万円を保証しない」と明言し、パイプライン10倍カバレッジ（qualified 100件 = ¥3,000万相当）で未達確率を下げる設計は誠実で正しい
- 値引き規律（半額枠は最大4件・2件超で再監査）、Edition台帳による限定性の証明、架空の希少性禁止 — ブランドを守る設計
- Stripe webhookのみをsource of truthとする計測設計も正しい

### 懸念点（率直に）

1. **分析過剰・実行ゼロのリスク**。戦略文書8本に対し、proof発注0、顧客インタビュー0、売上0。GPTの計画は「完璧な準備→launch」型で、HOLDが数ヶ月続く構造になっている。
2. **¥300,000×10〜12件が唯一の柱**。この価格帯の需要証拠がゼロのまま全体重を乗せている。月10人の新規高単価購入者は、現在の集客力では極めて重い。
3. **価格ラダーの欠落**。現在売れるものは¥980〜¥4,980のデジタルのみ。¥4,980と¥300,000の間に商品がない。中間価格帯の実売データなしにVIP価格の受容性は測れない。
4. **集客計画が薄い**。チャット営業モデルは月5,000会話を前提とするが、それを実現する流入計画が手紙SEO（効果は数ヶ月先）以外にない。
5. **税制の販売活用が未組込**。後述の通り、これは今の価格設定と完璧に噛み合う最大の見落とし。

## 4. 税制の正確な整理（重要な訂正あり）

まず用語の訂正: これは「税額控除」ではなく**損金算入（経費化）**。効果は「法人税の課税所得を減らす」であり、税額から直接引かれるわけではない。

事実関係（2026年7月時点）:

- **1点100万円未満の美術品は原則として減価償却資産**（耐用年数8年前後で経費化可能）— 平成27年改正以降の国税庁FAQによる扱い
- **中小企業の少額減価償却資産の特例**: 従来は取得価額30万円未満が対象だったが、**令和8年度税制改正により2026年4月1日以降取得分は40万円未満に拡大**。年間合計300万円まで、購入年度に**全額即時損金算入**できる

これが現行価格設定と完璧に噛み合う:

- **税抜30万円（税込33万円）のVIP版は「40万円未満」に収まり、中小企業なら購入年度に全額経費化できる**（税抜経理の場合。改正前の30万円枠では収まらなかったものが、今年4月から対象になった）
- 年間枠300万円 = 税抜36.6万円の作品なら約8点。「決算対策のオフィスアートまとめ買い」提案の根拠になる
- スタンダードライン（¥29,800〜98,000）も当然全額対象

### 活用方法

1. 法人向けLP「オフィスに音楽の美術館を」— 空間演出 + 即時経費化メリットを併記
2. チャットで法人意図を検知したら税制メリットに言及し問い合わせへ誘導
3. 決算期（3月・9月・12月）前のキャンペーン設計

### 表示上の注意

断定的な税務アドバイスは景表法・税理士法上のリスクがある。「税務上の取扱いは顧問税理士にご確認ください」を必ず併記し、「〜の場合、対象となり得ます」の表現に留める。適用には中小企業者等の要件・明細書添付等の条件がある。

出典: [国税庁 No.5408 少額減価償却資産の特例](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5408.htm) / [中小企業庁 少額減価償却資産の特例（40万円拡充）](https://www.chusho.meti.go.jp/zaimu/zeisei/pamphlet/syougaku_shisan.pdf) / [国税庁 美術品等についての減価償却資産の判定FAQ](https://www.nta.go.jp/law/joho-zeikaishaku/hojin/bijutsuhin_FAQ/index.htm)

## 5. 商材拡張

### ドローン写真

- 権利が完全にクリーン（自作）なので、ジャケットより販売障壁が低い
- 「空撮の高地」コレクションとしてサイトの世界観に組込済みの設計（AUTONOMOUS_EXECUTION_PLAN_v1 §C）を活かす
- **SSDが未接続のため中身を確認できない。接続してもらえれば、候補選定・トリミング・商品ページ化まで進められる**

### 生成AIアート

- 販売自体は可能。ただし2点厳守: (1) AI生成であることを明示（優良誤認回避）、(2) 日本では純粋なAI生成物の著作権保護が不確実なため、価値の根拠を「著作権」ではなく**物理的なEdition管理・署名・証明書・世界観**に置く
- 伯爵MUSIAMの世界観（地方・紋章・羊皮紙）と連動したシリーズにすれば独自性が出る

3. **YouTube**: ドローン映像 + 楽曲 → 概要欄からプリント販売へ
4. **プレスリリース**: 「音楽ジャケットのメタルプリント美術館」は記事化されやすい切り口
