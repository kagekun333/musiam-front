## 目的

2社以上から**同一条件**の見積を取り、スタンダードライン(A3〜A1)とVIP Edition(大判・最高仕上げ)の原価・納期・品質を比較確定する。これがHOLD解除(proof)と価格最終確定の前提になる。

## 粗利試算の枠(回答後に確定)

売価(税込) − (印刷原価 + 梱包送料 + 決済手数料3.6% + 再制作引当5%) = 粗利

目標粗利率: スタンダード 55%以上 / VIP Edition 75%以上。
例: A2売価¥69,800の場合、原価合計が¥31,400以下なら目標達成。
