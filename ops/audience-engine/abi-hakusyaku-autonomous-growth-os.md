## Growth-first funnel

`作品コンテンツ -> follow/save/share -> profile -> pinned invitation -> 伯爵Chat -> one-work diagnosis -> formal Offer`

- SNSの一次目的: 新規発見、継続視聴、世界観への信頼。
- 伯爵Chatの一次目的: 顧客に合う作品・商品・体験を一対一で選ぶ。
- 販売投稿の目的: 常時販売可能であることを知らせる。フィードを広告カタログにはしない。
- 最適化順: 3秒維持 -> 完視聴 -> 保存/共有 -> follow conversion -> profile visit -> Chat start -> qualified consultation -> non-refunded revenue。

## One-source, four-native-edits

同じ素材を単純転載しない。一つの作品から媒体固有の4編集を作る。

1. TikTok: 1秒目の驚き、短い結論、縦動画。
2. Instagram: 美術性、保存したくなるcaption、Carousel補足。
3. YouTube: Shortsに検索語、長尺で背景・制作過程。
4. X: 一文の思想、制作thread、画像または短尺。

全投稿にasset IDを付け、媒体・hook・CTAをUTMで追跡する。

## Autonomous weekly loop

1. `Inventory`: 新規・既存作品から30候補を抽出。
2. `Score`: novelty、visual impact、story、rights、sales fitを採点。
3. `Produce`: 上位14テーマから媒体別candidateを生成。
4. `Gate`: 権利、事実、品質、外部公開承認を検査。
5. `Publish`: 承認済みcandidateを公式APIまたは各社公式UI/schedulerで予約投稿。
6. `Observe`: 3秒維持、完視聴、保存、共有、プロフィール遷移、サイト訪問を取得。
7. `Learn`: 上位20%をシリーズ化、下位30%を停止。
8. `Sell`: プロフィール・固定投稿・明示的な関心への返信から伯爵Chatへ案内。

### Daily operating rule

- Instagram: Reels 2本、Stories 3–8枚。Carouselは週3本。
- Threads: 2–4投稿。問い、制作断片、コメント対話を中心にする。
- TikTok: 2–3本。最初の1秒と完視聴率のhook検証を担う。
- YouTube: Shorts 1–2本。長尺は週1本。
- 同一素材は媒体別にhook、尺、字幕、captionを変える。
- 毎日、前日上位20%のhookを再利用し、下位30%の構成を停止する。
- 直接販売投稿は全媒体合計の5%を超えない。

## Official automation boundary

- Instagram: Professional accountとMeta OAuthを使い、許可されたContent Publishing/Insightsだけ自動化。
- TikTok: Content Posting API。client audit完了までは公開投稿に制約があるため、初期は公式UIまたはdraft exportを併用。
- YouTube: YouTube Data API `videos.insert`。OAuth必須。未審査project経由uploadはprivate制約があるため、audit完了まで公式Studioを併用。
- X: X API v2で投稿・thread・metricsを扱う。従量課金開始はHuman cost Gate。

禁止:

- 非公式botによるアカウント自動作成・ログイン
- 自動follow/unfollow、like、反復comment
- follower購入、engagement pod、偽装interaction
- 無差別DM、同意なしの反復営業
- scrapingによる見込み客リスト作成
- password、recovery code、access tokenのリポジトリ保存
