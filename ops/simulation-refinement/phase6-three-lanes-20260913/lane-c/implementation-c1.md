# Lane C c1 implementation

This isolated candidate adds a deterministic repair for two observed structural gaps without changing r8, the root runtime, prompts, catalog knowledge, payment, authority, or quotas.

`count-action-completion.ts` distinguishes an explicit commercial opt-out from non-purchase browsing. `見るだけ` and `今日は買わない` do not become a persistent sales stop by themselves; `商品を勧めないで` remains an explicit stop. A persisted stop can be set aside only for a current product, price, purchase, delivery, refund, rights, or gift inquiry; that narrow fact answer does not generally reopen sales. A model-detected stop still applies for languages not covered by the local lexical classifier unless the current message is specifically browsing-only.

For a current positive request to listen, read, or open a specifically referenced earlier work, the semantic turn can restore one card only when the work is previously recommended, matches the requested medium, is not rejected, and has an existing public link. It does not choose a new work. It refuses links/cards declined by the user, a retracted action request, changed references, active opt-out, missing links, and ambiguous requests. The `actionCompletion` trace records `ACTIONABLE_COMPLETED` or `ACTIONABLE_BUT_NOT_COMPLETED` where applicable.

This addresses the P long turn 16 pattern at the structural level: the card is an existing public link for the eligible prior work. It does not claim that a specific sample was served, that the link plays successfully, or that its contents meet the earlier ambient request.
