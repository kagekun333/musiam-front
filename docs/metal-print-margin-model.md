## 4. 結論と意思決定ゲート

1. **VIP Edition(700角)は小売コストのままでも粗利78%**。価格戦略は既に成立している。VIPを40×60inで作る場合のみ原価が跳ねる(¥19万超)ため、700角を標準VIPサイズとするのが合理的。
2. **危険水域は「500角 ¥39,800」と「A1 ¥98,000」**。業者割引なしなら粗利12%/21%で、返品・破損・決済手数料(約3.6%)を吸収できない。
3. 意思決定ゲート(RFQ回答後)。判定基準は既定の目標粗利率(RFQ文書記載: スタンダード55%以上 / VIP 75%以上):
   - 業者価格が小売比 **-30%** の場合: A3(58%)・A2(60%)は目標達成、**500角(38%)・A1(45%)は未達** → この2サイズは¥49,800/¥118,000程度への改定、またはビジプリ(UV)への製造切替が必要
   - **-40%以上**: 500角47%・A1 53%でなお未達 → ChromaLuxe版500角・A1は「プレミアム仕上げ」として上位価格に再配置するのが現実的
   - つまり**どの割引率でも、500角とA1は現仮価格のままでは目標粗利に届かない可能性が高い**。RFQ回答前から価格改定またはUV方式併用を前提に検討を始めるべき
4. RFQ文面(docs/vendor-rfq-metal-print.md)に「**業者向けWEB注文システムの掛率/ボリュームディスカウント体系**」の質問が含まれているか送信前に再確認すること。ここが本モデルの最大変数。
