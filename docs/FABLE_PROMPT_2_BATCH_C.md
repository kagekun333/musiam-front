# Fable 5 実行プロンプト（第2弾・バッチC: 構成多様化）

前回セッションで65通（自著52＋外部商品8＋既存パイロット5）にAmazonアフィリエイトリンクと構成の手直しを実施済み（本番反映済み）。今回は残り約487通の「商品なしの構成多様化リライト」を担当してもらう。

コピペする前に、`docs/FABLE_WORKLOG.md` が前回セッションの内容のまま残っていることを確認しておくこと（Fableが最初に読みに行く前提資料）。

---

あなたは伯爵MUSIAM「伯爵の手紙」552通リライトプロジェクトを引き継ぐ。この会話には人間が張り付いていない。判断に迷っても聞き返さず、自分の判断で進め、根拠を作業ログに残すこと。

**最初にやること**: `docs/FABLE_WORKLOG.md` を読み、前回セッションの判断根拠・確定ルール・完了済み65通のリストを把握する。今回の作業もこの同じファイルに追記し続けること（前回のセクション構成を踏襲してよい）。

**今回のゴール**: 残り約487通（552通から前回完了の65通を除いた分）が対象。552通中546通が「一言書き出し→## 館より→## 伯爵の独白→## よくある質問→署名」という同一4部構成で書かれている単調さを崩し、読者が飽きずに読み続けられる手紙にする。アフィリエイトはあくまで前回同様の付随物であり、今回の主目的は構成・文章そのものの多様化。

**前提資料**（前回同様、作業前に目を通す）:
- `docs/PRODUCT_AND_AFFILIATE_STRATEGY.md` — ジャンル戦略、頻度ルール、「後出しじゃんけん」原則（第0章）
- `docs/LETTERS_ROADMAP.md` — 提案テンプレート型B（物語型）/C（制作ログ型）/D（対話再現型）/E（短文型）の定義
- `src/lib/letters.ts` — 使える記法（前回のFABLE_WORKLOG.mdにまとめ済みのはず）

**やってよいこと**
- 残り約487通に、ROADMAPの型B/C/D/Eをローテーションで適用し、機械的な同一構成を崩す。全通を同じ型にせず、その日の内容に合う型を選ぶ判断は任せる
- FAQを残すか間引くかは都度判断してよい。間引く場合は前回同様、Q&Aの実質的な内容を消さず、独白などの地の文に自然に溶かし込むこと（`the-honest-cat`での前回の処理が良い実例）
- 明らかに外部商品ジャンル（戦略ドキュメントの10分類）と相性の良い回を見つけたら、週1〜2回程度の頻度を目安に、前回と同じ`{sponsored}`記法・`?tag=hakusyaku04-22`・「後出しじゃんけん」原則で追加してよい（無理に探す必要はない。今回の主眼はあくまで構成多様化）
- 自著の新刊回でまだリンクが張られていないものを見つけたら、自著は頻度制限の例外というルールに従って追加してよい

**やってはいけないこと（前回と同じ・厳守）**
- 実在しないASIN・URLを創作しない。確認できない商品は本文に組み込まずスキップするか、`<!-- TODO: ASIN未確認 商品名: XXX -->` で止める
- 1通につき商品紹介は基本1つまで
- `docs/OTHER_PRODUCT_TRACKS.md`側の話題（グッズ/NFT/レコード/コーヒーOEM/家電の自社販売）には手を出さない
- 署名「**ABI伯爵**」は必ず維持する
- 本番への反映（git push）は行わない

**進め方について**
487通を今回のセッションで終わらせるのは非現実的。無理に急いで質を落とすより、確実に質を保ったまま進められるところまで進めるほうが良い。バッチの切り方・順序は任せる。ただし以下は必ず行うこと。
1. `docs/FABLE_WORKLOG.md`に「今回完了した手紙一覧（差分概要つき）」「未着手の残数」「次回セッションへの引き継ぎ事項」を追記する。
2. 「完了」と報告する前に、実際に編集したファイルをツールで読み直して確認してから報告する。
3. 利用枠が限られているため、Effortは高めに設定した上で、質を優先し、時間切れが近づいたら新しいバッチに着手せずログの整理に切り替えること。

まず`docs/FABLE_WORKLOG.md`を読むところから始めてよい。
