**2026年分特有の注意点**
- 2026年の手紙には実在の時事（サッカーW杯日本代表の戦績、日経平均の最高値更新、出生数統計、皇族数確保の議論、著名人の引退・結婚など）が事実として書き込まれている。**原文の事実関係を一切変えないこと。** 構成やトーンは自由に変えてよいが、日付・数字・固有名詞・試合結果などを書き換えたり、新しい「事実」を創作して足したりしない。
- 2026年1〜6月はリリース（新曲・新刊）がゼロの月が多い（works.jsonに releasedAt が無い）。そのため月次決算回（例: 2026-02-28, 2026-03-31, 2026-04-30, 2026-05-31, 2026-06-30）は「リリースなしでもその月をどう語るか」に工夫を凝らして書かれている。これらはA型維持（旧構成のままFAQ残置）が前回までの方針と一貫するので、無理に崩さなくてよい。
- 2026-04-30は「初リリースから1年」の周年回、2026-06-30はW杯ブラジル戦敗退と月次決算を統合した回など、単発イベントと月次決算を兼ねている手紙がある。構成を変える場合もこの兼務関係（複数の意味を持つ手紙であること）を壊さないこと。
