## 気づき・数字

- **記事2本 → /shop → mailto** という3ホップの最後だけが観測不能だった。LPやSEO記事を増やす前に、既存導線の終端が計測可能かを見る方が費用対効果が高い。監査の「Exact UTM attribution 0/10」の一因はここにもある可能性がある。
- ただし**記事側のUTMは /shop で消える**（shopのCTAが固定URLのため、`utm_source=tax_guide` が `utm_source=shop` に上書きされる）。どの記事から来た法人リードかは現状分離できない。→ 翌日の一手。
- 交易所のスタンダード枠は「価格 準備中」表示のまま。**価格を作らないゲートは維持**しつつ、意向だけを先に取る形にした（在庫・限定数の偽装表示は不使用）。
- パイプライン実測は Qualified 0 / Dossier accepted 0 / Purchase intent 0 / 非返金売上 0円 のまま。承認済みOffer容量は4作品12点・最大396万円で、**容量は目標を超えているのに入口が細い**という構造は不変。
- ベンダー未確定・価格未確定が**7営業日連続**でクリティカルパス。今日の変更は「その間に取れるリードを取り逃さない」ための保険であり、ボトルネック自体は動いていない。
