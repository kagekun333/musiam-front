# 全作品メタルプリント販売アーキテクチャ

Status: `ACTIVE`
Updated: 2026-07-25 JST

## 戦略判断

作品を1点または少数に限定しない。伯爵MUSIAMの公開作品カタログ全体を、受注生産メタルプリントの相談対象にする。

NATURAは品揃えを限定するための作品ではなく、価格、Stripe決済、原価、配送、制作手順を最初に固定した先行Offerである。

## 二層の販売状態

1. 全作品: 公開、発見、Chat相談、空間診断、見積候補。
2. Offer lock済み作品: 確定仕様、確定価格、決済、受注生産へ直接進める。

未検証作品へ一律の価格や仕様を付けず、顧客が選んだ作品から印刷適性と原価を確認して正式Offerへ昇格する。

## 顧客導線

`全作品カタログ -> 作品詳細 -> 作品ID付き伯爵Chat -> 空間診断 -> 印刷適性確認 -> 正式Offer -> Stripe入金 -> 制作発注 -> 直送`

## 営業原則

- 顧客に作品選択を丸投げしない。空間、用途、感情、予算からChatが候補を絞る。
- SNSでは入口となる代表作品を用いるが、販売可能性は全カタログへ開く。
- 正式Offer前に、原画解像度、権利、サイズ、地域別原価、納期を確認する。
- 売上は非返金の実決済のみを計上する。

## 次の拡張

Chat相談ログから選択頻度の高い作品を抽出し、順次、固定価格の直接購入Editionへ昇格する。需要調査を別工程にはせず、実営業データを品揃え拡張に使う。
